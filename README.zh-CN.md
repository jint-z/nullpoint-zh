# Nullpoint 使用说明

Nullpoint 是独立开发的非官方索尼耳机控制程序，与 Sony 没有关联。此版本基于 v1.2.0（b406e1a），提供简体中文和英文界面。许可证及协议来源见本目录的 LICENSE、NOTICE 和 Electron/Chromium 随附许可文件。

## Windows 安装版

在 Windows 10/11 x64 上运行 `Nullpoint-zh-Setup-1.2.6-x64.exe`。全新安装时可以选择目录；升级时安装器沿用已安装版本的范围和目录，并优先选择所有用户安装。向导会创建“Nullpoint”开始菜单和桌面快捷方式，也可以从 Windows 的“已安装的应用”中卸载。安装版与上游程序使用不同的应用标识、快捷方式和开机启动项。已发布的安装包及具体版本见本仓库 [Releases](https://github.com/jint-z/nullpoint-zh/releases)。

安装版将设置和会话数据保存在 `%APPDATA%\Nullpoint-zh`，与安装目录分开。升级前请从托盘完全退出程序；安装器会将该配置目录备份到 `%LOCALAPPDATA%\Nullpoint-zh-upgrade-backups`。如果发现较新版本、卸载器缺失或安装目录包含无法确认的文件，安装器会停止。卸载默认保留配置目录，以便重新安装后继续使用；如果确认不再需要设置，可以在退出程序后手动删除该目录。安装包的签名状态及验证范围以本地交付记录为准。

### 从中文便携版手动迁移设置

1. 先从托盘菜单完全退出便携版和安装版；如安装版尚未运行过，先启动一次再完全退出，使配置目录创建完成。
2. 打开便携版 `Nullpoint.exe` 旁的 `nullpoint-data` 文件夹，以及安装版的 `%APPDATA%\Nullpoint-zh` 文件夹。
3. 如安装版已有 `settings.json`，先备份；然后将便携版的 `settings.json` 复制到安装版目录，不要复制缓存、浏览器会话或整个数据文件夹。
4. 重新启动安装版并检查语言、自动重连、快捷键和其他设置。迁移仅复制文件，不会删除便携版原有数据。

## 中文便携版

在 Windows 10/11 上运行 `Nullpoint.exe`，无需安装。右下角的 `EN` 按钮切换英文，`中文` 按钮切回简体中文；语言设置会保存。程序默认关闭窗口后继续在系统托盘运行，要完全退出请右键托盘图标选择“退出 Nullpoint”。

本便携版把配置存入程序旁边的 `nullpoint-data` 目录，与之前测试的英文版独立。该目录必须可写；移动整个文件夹时可一并保留。首次启动默认为中文，开机启动默认关闭，自动重连和全局快捷键默认开启。全局快捷键为 Ctrl+Alt+N 循环切换模式，Ctrl+Alt+1/2/3 分别选择降噪、环境音和关闭。多个 Nullpoint 实例可能争用快捷键与耳机控制通道。

## 连接耳机

1. 先在 Windows 蓝牙设置中配对并连接耳机，确保耳机已开机。
2. 回到 Nullpoint，点击“连接耳机”或“连接其他耳机”。若另一台设备或另一个程序占用控制通道，先释放该连接，再重试。
3. 连接后显示耳机报告的状态。自动重连、声音、均衡器和设备列表功能的可用性由耳机实际报告的能力决定；不同型号与固件可能不同。

音乐播放由操作系统处理。音频已经播放并不必然表示耳机的控制通道可用。程序可能显示浏览器或系统设备选择器，具体选项由系统决定。

## 常用功能

- WH-1000XM6 的“自动关机”仅提供摘下后自动关机和不自动关机；按 Sony 说明，默认摘下约 15 分钟后关机。该型号不提供自选闲置时间；其他型号的选项可能不同。
- 降噪控制可选择降噪、环境音或关闭；环境音开启后可调整级别、关注人声，以及耳机支持时的自动环境音。
- 聆听模式可选择标准、背景音乐或影院混音；背景音乐的房间大小由耳机支持情况决定。切换后会回读耳机状态，无法确认时会提示重试。
- 均衡器根据耳机报告的布局显示预设与频段；可保存命名曲线。设备上的预设和自定义曲线支持因机型及固件而异。
- 显示电量和设备列表；耳机支持时可切换音频来源，或连接、断开已配对设备。连接第三台设备可能挤掉原来的一个连接。
- “更多功能”区域按耳机能力显示 DSEE、智能免摘对话、摘下暂停、自动关机等选项。锁定智能免摘对话后，应用可能自动将它恢复为锁定值。
- 设置页面包含主题、强调色、自动重连、快捷键、耳机能力、协议检查器和空间音效演示。协议记录可能包含设备名称或地址，分享前应自行检查。

## 已知边界

- WH-1000XM6 上已测试聆听模式与降噪切换；连接仍可能较慢，个别测试超过 10 秒。其他型号、EQ 和多点等功能应以自己的设备实测为准。
- 状态变化和 ACK 不总能证明耳机实际采用了设置；必要时重新读取，并结合实际声音或设备行为核对。建议在测试前记录原设置，测试后恢复。
- 未加入固件更新、Sony 账号或云功能。原版 Windows 发行程序和现有中文便携版没有 Authenticode 数字签名；安装包的签名状态以 Release 说明为准。
- 安全和兼容性检查不能覆盖所有依赖、系统及固件；未对所有支持型号进行实机验收。

## 源码与构建

使用 Node.js 22+ 和 pnpm 11.21.0，运行 `pnpm install --frozen-lockfile`，然后执行 `pnpm -r run build`、`pnpm -r run typecheck` 和 `pnpm -r run test`。桌面设置与安装版配置检查分别为 `node validation/settings-check.cjs` 和 `node validation/install-profile-check.cjs`。在 Windows 上运行 `pnpm --filter @ssc/desktop exec electron-builder --config electron-builder.yml --win --x64`，安装包输出到 `apps/desktop/release/`。

已有 Windows 便携版复用了原发行包的 Electron 运行时，并替换了本地应用资源；安装版由本仓库源码构建。两者均为非官方版本。
